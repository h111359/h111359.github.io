## Goal

Enable the site owner to create, configure, populate, edit and preview static trip journals from trips/data_editor.html using double-click Linux and Windows launchers, eliminating remembered generator arguments and separately coordinated registry writes. Extend the editor, add Python standard-library helpers under trips/scripts/, align the template, and document and verify the complete workflow.

## Constraints

- Python 3.10+ standard library only; no package manager, build system or production backend. Published HTML/CSS/JavaScript and existing GALLERY_EVENT_INDEX and GALLERY_ITEMS schemas remain static and compatible.
- New trips belong exclusively to trips/<slug>/ and originate from trips/template/. Existing trips/china/ and trips/2026/ content is excluded from implementation changes. Do not publish, commit or push. Do not alter scripts/generate_trip_event.py or its tests; reuse its functions through repository-relative loading.
- Bind only to loopback. Serve constrained repository static files; prohibit internal/hidden paths, traversal and symlink escapes. Allow writes only to validated trip configs, registries and event files, plus exclusive creation from the template. Reject reserved trip directories and cross-platform invalid/colliding names. Browser checks never replace service validation.
- Preserve existing item CRUD, rich text, visibility, flips, rotation, ordering, AI controls, handle restoration and guarded five-second foreground polling. Manual data-folder mode remains available in Chromium; trip discovery, config access and Drive generation require helper mode because a data-folder handle does not authorize parent access.
- Use Bulgarian/bg-BG defaults and selectable English with complete label presets; preserve custom labels/theme values when changing language. Public Drive folders only, direct children only, no credentials or recursive discovery. Do not persist folder URLs in public schemas.
- Decisions resolved by the user: deletion removes both registration and data after explicit consent; saved slug/filename remain fixed; generated slugs use documented Bulgarian-to-Latin ASCII transliteration; configs preserve unknown JSON-compatible literal fields and reject executable syntax; Linux uses a repository-local relocatable desktop entry without an installer; registry changes require repair of all legacy registry errors; coordinated operations use runtime rollback only; preview offers confirmed saving of all affected valid drafts and stops on cancellation or save failure.
- Runtime rollback does not guarantee recovery from process termination, power loss or failed restoration. Retain originals during operations, surface recovery locations and block subsequent writes after a failed restoration. Do not introduce a persistent restart journal.
- Linux desktop trust and installed Python are prerequisites. Derive the Linux repository location from the desktop entry location, including file URI decoding; do not assume the working directory. Validate the actual desktop/file manager and Windows behavior before claiming launcher acceptance. Unavailable platforms or a missing public Drive test URL must be reported as unverified acceptance items.
- Modify trips/shared/gallery.js only for a demonstrated single-part defect; no gallery redesign or unrelated cleanup. Keep context Product and portfolio rules unchanged.

## Success criteria

- Linux and Windows double-click launch starts a loopback server and opens the editor from repository paths containing spaces and non-ASCII characters; an occupied port or absent Python gives an actionable error, and stopping the launcher closes the server.
- Discovery lists valid trips and excludes template/shared/scripts and unsafe paths. Manual folder mode retains existing editing. Switching trips cannot lose dirty drafts or apply stale polling/AI results to the new selection.
- Creating with only a name produces a selectable empty trip under trips/<ASCII-slug>/ with corrected shared assets and Bulgarian defaults. Existing targets, case collisions, reserved names and symlink escapes cause no writes. Optional Drive failure leaves the explicitly created empty trip usable.
- Settings round-trip supported identity, language/locale, theme and labels plus unknown JSON-compatible values. Unsupported executable syntax blocks saving without data loss. BG and EN have complete localized labels and preserve overrides.
- Reviewed generation reports included/skipped media, requires confirmation, and writes one event plus one registry entry together. Validation failures, stale versions, duplicate confirmation and rejected overwrite preserve original files. Replacement explicitly warns of lost descriptions, text blocks, visibility, corrections and ordering.
- Registry add/edit/reorder/delete works with stable selection. Saved identities remain locked. Invalid legacy registries remain readable with existing-event editing, but all registry-changing saves require complete repair. Confirmed deletion removes both artifacts and rejects remaining references to the data target.
- Injected generation, deletion and multi-draft preview write failures restore originals during runtime; failed restoration preserves recoverable originals and reports a blocked state. No crash-recovery guarantee is claimed.
- Preview opens the correct local trip URL and selected encoded #event hash in a new tab after confirmed saving of valid affected drafts. Cancellation or any failed save prevents opening. Empty, exactly-one-part and multiple-part trips behave correctly.
- Existing generator tests and new network-free helper and browser tests pass. Manual regression covers rich text, media corrections/visibility, ordering, AI controls, session restoration and polling in helper Chrome/Firefox/Edge and Chromium fallback; real launchers and a supplied public Drive folder are checked separately.
- trips/README.md describes the canonical layout and complete authoring workflow; .aib_memory/context.md records current paths, the local-only helper exception, resolved policies and critique findings.
