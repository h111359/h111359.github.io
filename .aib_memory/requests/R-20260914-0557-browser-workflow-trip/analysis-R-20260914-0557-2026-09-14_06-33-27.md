## Overview

Request ID: R-20260914-0557

Request title: Локален browser workflow за trip страници

### Background

The site owner needs to create and edit trip journals without remembering generator arguments, coordinating separate registry edits, or configuring a preview server.

### Scope

Extend the existing trip editor with discovery, creation, settings, part management, reviewed Drive generation and preview; add standard-library Python helpers under trips/scripts/, Linux and Windows launchers, template alignment, automated checks and documentation.

### Out of scope

No publishing, Git operations, Drive authentication or recursive discovery, production backend, existing China/2026 content changes, or gallery redesign. Shared gallery changes are permitted only for a demonstrated single-part defect.

### Industry knowledge

- Python documents that SimpleHTTPRequestHandler follows symbolic links. Applicability: constrain resolved static paths to the repository, reject private/internal paths and traversal, and constrain writes further to allowed trip files; simply choosing a serving directory is insufficient. Source: [Python HTTP server documentation](https://docs.python.org/3/library/http.server.html).
- Python documents os.replace as a single-path replacement operation, with possible cross-filesystem failures. Applicability: stage in the destination filesystem; two replacements do not provide a transaction over event and registry. Use serialized commits, version checks, retained originals and rollback; persistent crash recovery is a separate decision. Source: [Python 3.10 os documentation](https://docs.python.org/3.10/library/os.html#os.replace).
- The Desktop Entry specification defines Exec parsing, quoting and working-directory fields rather than shell expansion. Applicability: a relative script path cannot safely depend on the file manager working directory; choose a relocatable entry bootstrap or an explicit one-time generated launcher, then test the selected desktop environment. Source: [Desktop Entry specification](https://specifications.freedesktop.org/desktop-entry/latest-single/).
