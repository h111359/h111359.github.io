## Input

The site in `202507_china` is visible but sounds old facion. Modernize it. 
Make it according the latest and best UX design rules and make me be proud of this site
Scope: the site in folder 202507_china
DO NOT change files outside 202507_china
Do not change the files in folders `202507_china/data` and `202507_china/materials`

### Goal

Modernize the public China trip gallery as a refined, media-first travel journal for family and friends. Deliver a coherent Bulgarian experience that feels contemporary, warm, cinematic, accessible, and easy to navigate across the full trip.

### Primary Audience

- Family and friends viewing the Hristov family’s China trip memories.
- No additional impacted user groups are in scope.

### Visual Direction

- Use a warm editorial travel-journal aesthetic.
- Emphasize photography and storytelling through generous spacing, strong typography, and restrained visual hierarchy.
- Use subtle China-inspired colors or details without clichés or excessive decoration.
- Use system fonts and locally implemented styling only.
- Avoid a dense administrative, generic template, or playful scrapbook appearance.

### Scope

Modernize only the public gallery through changes to:

- `202507_china/index.html`
- `202507_china/style.css`
- `202507_china/app.js`

Deliver:

- A refined introductory header using the existing trip title and family subtitle.
- Optional trip dates and event count only when derived from the event registry.
- A responsive event navigator grouped by travel date.
- Search within the event navigator.
- A compact drawer-style event navigator on small screens.
- A responsive editorial gallery grid with varied media presentation.
- Full-width presentation for story text blocks.
- A refreshed version of the existing basic open-and-close lightbox.
- Bulgarian controls, status messages, error messages, and accessibility labels.
- Visitor-friendly content presentation without technical filenames or redundant media-type labels.
- Graceful interface-level handling of duplicate events and missing event titles.

### Functional Requirements

- Preserve the existing order of photos, videos, descriptions, and text blocks within every event.
- Preserve all existing authored text without rewriting it.
- Continue loading media from the existing Google Drive references.
- Preserve hash-based event URLs, bookmarking, browser Back behavior, and browser Forward behavior.
- Group event choices by date without changing the event registry.
- Provide event search that filters available events using their displayed labels.
- Deduplicate repeated registry entries in the rendered navigator without modifying source data.
- Generate a readable Bulgarian-facing fallback label from an event slug when its registry title is empty.
- Keep the lightbox limited to the current basic interaction model: open selected media and close it.
- Do not add previous/next navigation, swipe navigation, an item counter, or other new lightbox browsing features.
- Retain Escape-key closing and add only the focus handling required for keyboard accessibility.
- Show useful Bulgarian loading, empty, and failure states.
- Keep media lazy-loaded where appropriate and prevent avoidable layout shifts.

### Accessibility and Responsive Requirements

- Align the public interface with WCAG 2.2 Level AA.
- Support viewport widths from 320 CSS pixels upward without horizontal page scrolling or lost content.
- Make all interactive controls operable by keyboard.
- Provide visible keyboard focus states.
- Use semantic landmarks, controls, labels, and dialog behavior.
- Return focus appropriately after the lightbox or mobile navigation drawer closes.
- Maintain at least WCAG AA text and control contrast.
- Provide practical touch target sizes.
- Respect `prefers-reduced-motion`.
- Do not make essential content dependent on animation.
- Support current stable versions of Chrome, Firefox, Safari, and Edge.

### Content Rules

- Retain the existing title: “Пътуване до Китай - юли 2025”.
- Retain the existing family subtitle: “Едно пътешествие на семейство Христови”.
- Do not invent narrative copy, destinations, dates, statistics, or trip facts.
- Display only facts derived reliably from the existing event registry.
- Hide filenames and technical media labels when they provide no useful visitor context.
- Preserve trusted rich-text rendering for existing event descriptions and text blocks.

### Constraints

- Keep the site fully static.
- Use only native HTML, CSS, and vanilla JavaScript.
- Introduce no build tools, frameworks, third-party JavaScript libraries, externally hosted fonts, or other new dependencies.
- Do not change any file outside `202507_china`.
- Do not change any file in `202507_china/data`.
- Do not change any file in `202507_china/materials`.
- Do not modernize `comments_index.html`, `comments_styles.css`, `comments_app.js`, or `data_editor.html`.
- Do not alter the stored gallery content or Google Drive media references.
- Do not require server-side behavior.

### Out of Scope

- Editing or correcting the protected event registry and event content files.
- Modernizing the comments utility or data editor.
- Rewriting trip descriptions.
- Creating new media or replacing existing media.
- Adding multilingual support.
- Adding accounts, comments, uploads, analytics, or server-side features.
- Expanding the lightbox into a carousel or advanced media browser.

### Acceptance Criteria

- The public gallery presents a coherent warm editorial travel-journal design.
- All visible interface copy is Bulgarian.
- Visitors can browse events through a date-grouped navigator and filter its choices by text.
- The navigator becomes a compact accessible drawer on small screens.
- Duplicate registry entries appear only once in the rendered navigator.
- An event with an empty title receives a readable label derived from its slug.
- Selecting an event updates the URL hash, and bookmarked event links plus browser Back and Forward continue working.
- Gallery content remains in its original source order.
- Story text spans the appropriate full content width, while media uses a responsive editorial grid.
- Technical filenames and redundant media-type captions are not exposed in the normal visitor experience.
- Images and videos still load from their existing Google Drive references.
- The basic lightbox opens and closes correctly by pointer and keyboard without gaining carousel features.
- The layout works at 320px and wider without horizontal page overflow.
- Keyboard users can reach and operate every control with visible focus.
- Dialog and drawer focus is managed and returned to the initiating control when closed.
- Reduced-motion preferences are honored.
- Automated or manual checks confirm WCAG AA color contrast.
- Current Chrome, Firefox, Safari, and Edge can use the core gallery functionality.
- No third-party dependency or build step is introduced.
- Git changes are limited to the three public-gallery files named in Scope.
- Files under `202507_china/data` and `202507_china/materials` remain unchanged.
